# St Sava Church Register

Touchscreen sales register for St Sava Church West Ealing. Includes product management, basket, cash sales, a staff PIN screen, and the matching St Sava green-and-gold app icon.

## Android app

The Android APK is built automatically from the latest version of the register.

- **[Download the latest Android APK](https://github.com/lukakrivosic100-finance/Church-iPad-Register/releases/download/church-register-android-latest/app-debug.apk)**

On your Android device, open the download link, download the APK, then tap the downloaded file to install it. Android may ask you to allow your browser or file manager to install apps from that source.

The APK is a standalone Android package. The iPad version remains available as a Safari Home Screen web app.

## Important data note

Products and sales are stored locally on each device/browser. They do not automatically sync between the iPad and Android devices. Export or back up sales records regularly.
